# Plumit · Бухгалтерия проектов

Веб- и мобильное приложение для учёта денег по проектам студии вместо Excel.
Мобильная версия — PWA: открываете сайт на телефоне и добавляете на главный экран, оно работает как обычное приложение.

## Что умеет

| Было в Excel | Стало в приложении |
|---|---|
| Лист на проект, блоки по месяцам | **Проекты** → карточка проекта с вкладками |
| «Итерация» + столбцы с долями разработчиков | **Итерации**: пункт работ, стоимость для клиента, кто сколько получает; статус (в плане / в работе / сдано / отменено). Кнопки «Как в прошлой» и «Поровну» |
| Строки «Поступления / Платежи / Налоги» по дням | **Операции**: поступление (аванс), выплата, расход, налог/взносы, штраф, перевод внутри команды. Вкладка «По дням» показывает ту же таблицу, что в Excel |
| «Стоимость работ / Выплачено / Осталось выплатить» | Считается автоматически: начислено по итерациям − штрафы − выплачено. Кнопка «Выплатить» подставляет остаток |
| «Расходы: Точка, Взносы, Сервера» | Расходы со статьями, можно без привязки к проекту |
| «Журнал расходов» текстом | Переводы между людьми + комментарии к любой операции |
| «Чистые» | Чистые (план) = стоимость проекта − начислено команде − расходы − налоги |

Ещё: сводка по всем проектам с графиком движения денег за 12 месяцев, долг перед каждым участником, выгрузка в CSV (открывается в Excel), светлая/тёмная тема, пользователи с правами «администратор» или «только просмотр».

## Запуск локально

Нужен Node.js 22.5+ (используется встроенный SQLite, без нативных зависимостей).

```bash
npm install
npm run seed      # необязательно: вымышленные демо-данные
npm run dev       # API на :3000 + интерфейс на http://localhost:5173
```

При первом запуске создаётся администратор. Логин `admin`, пароль задаётся через `ADMIN_PASSWORD`; если переменная не задана, случайный пароль печатается в консоль.

Тесты API: `npm test`.

## Продакшен

```bash
cp .env.example .env   # задайте ADMIN_PASSWORD
docker compose up -d --build
```

База данных — один файл `data/plumit.db`. Резервная копия — просто копия этого файла.
Поставьте перед приложением nginx или Caddy с HTTPS (на телефоне PWA устанавливается только по HTTPS), например `buh.plumit.ru`.

Без Docker: `npm ci && npm run build && ADMIN_PASSWORD=... npm start`.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `DB_FILE` | `data/plumit.db` | путь к базе |
| `ADMIN_LOGIN` / `ADMIN_PASSWORD` / `ADMIN_NAME` | `admin` / случайный / `Администратор` | первый пользователь (создаётся, только если пользователей ещё нет) |
| `COOKIE_SECURE` | `0` | `1` — cookie только по HTTPS |
| `TRUST_PROXY` | `0` | `1` — если сервер стоит за обратным прокси |

## Фирменный стиль

Все цвета и шрифт задаются токенами в начале `src/styles.css` (`--accent`, `--bg`, `--font` и т.д.) отдельно для светлой и тёмной темы. Чтобы привести приложение к стилю plumit.ru, достаточно поменять этот блок и иконку `public/icon.svg` (PNG-иконки `public/icon-192.png` и `public/icon-512.png` нужно пересохранить из неё).

## Устройство

- `server/` — Express + SQLite (`node:sqlite`). Суммы хранятся в копейках. Расчёты — в `server/finance.js`.
- `src/` — React + Vite. `public/sw.js` — service worker: интерфейс работает офлайн, данные всегда берутся с сервера.
- Если понадобятся приложения в App Store / Google Play, тот же код можно упаковать через Capacitor.
